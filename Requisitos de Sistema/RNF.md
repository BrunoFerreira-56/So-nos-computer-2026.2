# 1. Requisitos Não Funcionais

<p align="justify">A <i>Tabela 2</i> a seguir contém os <b>Requisitos Não Funcionais (RNF)</b> elicitados utizando a técnica de Brainstorm .</p>

| ID   |                                 Requisito NF                              | Categoria/Tipo | Prioridade | Requisitos Relacionados |
| :--: | :-----------------------------------------------------------------------: |:-------------: | :--------: | :-----------------: |
| RNF01 |  O cadastro e o login devem ser feitos exclusivamente com o email institucional | Segurança/Privacidade               |Alta       |      -           |
| RNF02 | O Hub principal deve ser carregado em até 2 segundos com a internet em estado normal     |  Produto/eficiência     |Alta        |        -         |
| RNF03 |  As mensagens devem ser enviadas em tempo real, com atraso de no máximo 500 ms.              |  Desempenho |Média       |     -               |
| RNF04 |  A interface do hub e do chat devem ser 100% responsivas.              |  Usabilidade/Acessibilidade |Alta       |     -               |
| RNF05 |  Um novo usuário deve conseguir acessar o chat ou criar uma venda com apenas três cliques a partir da tela inicial.              |  Usabilidade/Acessibilidade |Média       |     -               |
| RNF06 |  O marketplace deve se manter ativo 24h por dia, 7 dias na semana.              |  Disponibilidade/Confiabilidade |Alta       |     -               |
| RNF07 |  As mensagens do chat não devem ser perdidas em caso de queda do servidor ou desconexão do usuário.              |  Disponibilidade/Confiabilidade |Alta       |     -               |
