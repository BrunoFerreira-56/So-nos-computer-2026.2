# 1. Requisitos Funcionais

<p align="justify">A <i>Tabela 1</i> a seguir contém os Requisitos Funcionais (RF) elicitados utizando a técnica de Brainstorm.</p>

| ID   |                                 Requisito                                 | Prioridade | Requisitos Relacionados |
| :--: | :-----------------------------------------------------------------------: | :--------: | :---------: |
| RF01 |              O usuário deve acessar um sistema de login.                  |  Média     |     -       |
| RF02 |         O usuário deve poder visualizar os anúncios presentes.            |  Alta      |     -       |
| RF03 |     O usuário deve poder interagir com os anúncios disponibilizados.      |  Baixa     |     -       |
| RF04 |             O usuário deve poder favoritar anúncios de seu interesse      |  Baixa     |    RF02     |
| RF05 |         O usuário deve poder entrar em contato com os anunciantes.        |  Alta      |    RF01     |
| RF06 |              O usuário deve poder cadastrar novos anúncios.               |  Alta      |    RF02     |
| RF07 |     O usuário deve poder editar ou excluir os anúncios criados por ele.   |  Média     | RF02, RF06  |
| RF08 |       O sistema deve permitir filtrar os anúncios por campus da UTFPR     |  Média     |     RF02    |
| RF09 |       O usuário deve poder buscar anúncios por meio de termos-chave.      |  Alta      |     RF02    |
| RF10 |      O usuário deve poder marcar anúncios como "Vendido" ou "Inativo"     |  Média     |  RF02, RF07 |
| RF11 |      O sistema deve fornecer um chat interno para discussão.              |  Alta      |     RF04    |
| RF12 |    O sistema deve permitir a recuperação de senha de acesso via e-mail.   |  Baixa     |     RF01    |
| RF13 |        O usuário deve poder reportar anúncios ou perfis suspeitos.        |  Média     | RF02, RF03  |
| RF14 |              O usuário deve poder avaliar outros usuários.                |  Baixa     | RF04, RF11  |
